# 🧺 Fresh Laundry – حاسبة تكلفة الغسيل

## وصف المشروع
مشروع تدريبي بسيط لتطبيق أساسيات PHP من خلال إنشاء حاسبة لتكلفة خدمات مغسلة الملابس.

تتيح الصفحة للمستخدم إدخال عدد القمصان والبناطيل وسعر كل قطعة، ثم يقوم البرنامج بحساب تكلفة كل نوع وعرض التكلفة الإجمالية بالريال السعودي (SAR).

## التقنيات المستخدمة
- **HTML:** إنشاء صفحة الويب والفورم (Form).
- **CSS:** تنسيق وتصميم واجهة المستخدم.
- **PHP:** استقبال البيانات وتنفيذ العمليات الحسابية وعرض النتائج.

## هيكل المشروع

```text
fresh-laundry/
│
├── index.php
├── calculate.php
├── style.css
└── README.md
```

## آلية عمل المشروع
1. فتح الصفحة الرئيسية `index.php`.
2. إدخال عدد القمصان (Number of Shirts).
3. إدخال سعر القميص الواحد (Price per Shirt).
4. إدخال عدد البناطيل (Number of Pants).
5. إدخال سعر البنطلون الواحد (Price per Pants).
6. الضغط على زر Calculate Total.
7. إرسال البيانات إلى `calculate.php` باستخدام طريقة POST.
8. حساب تكلفة القمصان والبناطيل والتكلفة الإجمالية وعرض النتائج.

## المطلوب تطبيقه في PHP

- إنشاء المتغيرات (Variables).
- استقبال البيانات باستخدام `$_POST`.
- استخدام عملية الضرب (Multiplication).
- استخدام عملية الجمع (Addition).
- عرض النتائج باستخدام `echo`.

## مثال على المدخلات والنتائج

| البيان | القيمة |
|---|---:|
| Number of Shirts | 3 |
| Price per Shirt | 5 SAR |
| Number of Pants | 2 |
| Price per Pants | 8 SAR |
| Shirts Cost | 15 SAR |
| Pants Cost | 16 SAR |
| **Total Cost** | **31 SAR** |

## الهدف التعليمي
التدرب على أساسيات PHP وفهم كيفية:
- استقبال البيانات من HTML Form.
- تخزين البيانات في Variables.
- تنفيذ العمليات الحسابية.
- استخدام POST لإرسال البيانات بين صفحات PHP.
- عرض النتائج داخل صفحة الويب باستخدام `echo`.

## طريقة تشغيل المشروع

1. فتح برنامج XAMPP.
2. تشغيل Apache.
3. وضع مجلد المشروع `fresh-laundry` داخل مجلد `htdocs`.
4. فتح المتصفح وإدخال الرابط التالي:

```text
http://localhost/fresh-laundry/index.php
```

## ملاحظات

- يجب التأكد من تشغيل Apache قبل فتح المشروع.
- يتم تنسيق الصفحات باستخدام ملف `style.css`.
